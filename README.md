# Social Media Trends Analyzer

A Data Engineering and Analytics project that identifies trending places, events, and topics from YouTube and other social media platforms.

## Features

- YouTube trending video collection
- Trend analysis
- Location extraction
- Sentiment analysis
- Dashboard reporting

## Technology Stack

- Python
- YouTube Data API
- Pandas
- Streamlit
- GitHub

## Roadmap

- YouTube integration
- Instagram integration
- Facebook integration
- Real-time dashboard
